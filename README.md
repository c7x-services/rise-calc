# Калькулятор на Выживание бомжа

Небольшая утилита, в которой настраиваешь текущее перерождение, баланс и заработок, и оно отображает ETA до перерождения, а также предлагает лучшие бизнесы по выдаче.


# Функции

Есть несколько флагов:
+ показать уже купленные бизнесы
+ списывать деньги за покупку
+ добавлять заработок за покупку (требуется автоустановка множителя дохода)

Сайт автоматически считает каждую секунду дохода и знает все бизнесы, все координаты, так что с ним легко быстро развиться


## Как работает подсказка бизнеса

Берутся все бизнесы, для каждого индивидуально рассчитывается сколько уровней можно купить максимум, из этого берётся сколько потенциального дохода и трат, после этого происходит сортировка по коэффициенту доход/траты


## А зачем множитель заработка? Как он рассчитывается?

Множитель заработка нужен для флага "Добавлять заработок за покупку". Сайт знает, сколько бизнес даёт без множителя, а для корректной добавки требуется множитель заработка.

Рассчитывается так: берём сумму всех доходов с бизнесов, которые вы отметили как купленные на сайте. Берём заработок из UI. Делим заработок из UI на сумму доходов. Магия.
